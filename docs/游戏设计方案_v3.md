## 〇、设计总纲

### 目标玩家：8-10 岁（小学 2-4 年级）

这个年龄的真实边界：

- **阅读**：能独立读短句，长段落会累。一屏 100 字就是「又要读一大堆」。
- **心算**：2 年级 100 以内加减 + 表内乘法；3 年级万以内加减 + 多位数乘一位数 + 除法；4 年级三位数乘两位数 + 四则混合。
- **挫败容忍**：低。连续失败 2-3 次就会放下不玩了。
- **成就感来源**：**「我变强了」+「我知道得更多了」**，而不是「我通关了」。

### 三条硬约束

整个设计都要服从它们：

1. **死亡必须教会东西。** 死亡可以发生，但每一次死亡都要留下确定、可复用的情报（详见 ★ 节）。
2. **不能有看起来像陷阱的选项。** 孩子会自责选错了，而不是觉得游戏设计有问题。扣血的选项必须在选之前就显示代价（详见 ★ 节末）。
3. **文字是装饰，不是关卡。** 读懂剧情应该让游戏更有趣，而不是成为通关的必要条件。

### 已定的产品决策

| 事项 | 决定 |
| --- | --- |
| 种族数量 | **5 个**，每个种族有只属于它的能力，差异是玩法不是强弱（见 1.10） |
| 每屏文字量 | **≤60 字** |
| 难度选择 | 要，**藏在给家长看的设置里**，不给孩子选 |
| 隐藏主线 | 占位，暂不设计，生成的任务里先不出现 |
| 世界背景 | 动乱的世界：九星连珠之后，世界各地出现各种魔物，冒险者应运而生；这个背景在游戏中逐渐铺垫开来（见叙事结构） |
| 语言 | 中文，数学题按 2-4 年级课标出 |
| 登录 | 登录界面有一个密码框和一个确认按钮，输入口令登录；口令输错时提示「密码错误，请重新输入」并清空密码框；浏览器记住已登录，下次不用再输（见第五节「登录」） |
| 敌人 | 分种族，有基础值，每级按种族偏向随机分配属性点；种族带克制标签（弱魔法 / 弱物理 / 无弱点），标签默认看不到；克制伤害 ×1.5（见 1.11） |
| 任务发布 | 冒险公会每天早上 6:00 随机发布 6-8 个任务；完成 10 个任务后发布 S 级赏金任务，完成后进入下一个世界危险等级，共 20 级（见 3.9） |

### 核心循环

```
小镇公会 ──▶ 看悬赏 ──▶ 判断「我打不打得过」──▶ 出发
   ▲                                              │
   │                                              ▼
   └── 交任务拿报酬 ◀── 战斗/解谜 ◀── 途中遭遇（数学题、抉择）
                              │
                              ▼
                        死亡 ──▶ 重生（丢本次地下城的收获，保留属性与记忆）
                              │
                              └──▶ 回到公会（但你知道得更多了）
```

**「判断打不打得过」是整个游戏最核心的思考动作。** 其他所有系统都是为它提供信息、或为判断失误兜底。

### 叙事结构

- **一个中心小镇**（冒险公会所在地）
- **地下城由冒险公会发布的任务生成**，每个任务是一座全新的地下城，每座一个悬疑剧本，一趟 10-15 分钟（见 3.9）
- **世界背景**：这是一个动乱的世界。九星连珠之后，世界各地出现了各种魔物，冒险者应运而生。这个背景在游戏中逐渐铺垫开来，不一次讲完。
- **隐藏主线**：占位，暂不设计，生成的任务里先不出现。

任务之间互相独立、可任意顺序接取。对儿童来说，「我自己选」比「按顺序来」重要得多。

## ★ 死亡政策（2026-10-08 立）

**本设计不设「任何失败都不能让孩子觉得我不会」这条约束。** 理由：它与重生题材冲突——不死的游戏里，「重生保留记忆」是句空话。若把死亡率压到那条约束要求的水平，绝大多数玩家全程不会死，最核心的机制变成死代码。

**核心约束只有一句：**

> ### 死亡必须教会东西。
>
> 每一次死亡都要留下**确定、可复用、下次用得上**的情报。

死亡从「不能发生」变成「发生但必须有所得」。这条约束管四件事：

| # | 要求 | 说明 |
| --- | --- | --- |
| 1 | **死因必须可理解** | 孩子要能说出「我是被那个东西打死的」，不是「莫名其妙就没了」 |
| 2 | **死因必须可复现** | 同一处、同一动作，下次还会死。**死亡是知识，不是随机** |
| 3 | **必须留下具体情报** | 敌人弱点、陷阱位置、正确解法、题目提示（见 2.1 与 2.2b） |
| 4 | **重生后必须能立刻用上** | 情报要在下一次尝试里发挥作用，不能只是躺在日志里 |

### 死亡率的定位：难度旋钮，不是禁区

死亡率由玩家 HP 和敌人伤害共同决定，是调难度的旋钮：

1. **HP 越低，死亡越常见。** HP = 体力属性（1:1），所以死亡率随等级成长而下降。Lv1 的体力定为 10（见 1.1）。
2. **决策也会造成死亡。** 战斗答错、机关陷阱、装备陷阱都会扣血（见 1.7）。

具体死亡率靠试玩观察，文档里不保留死亡率数字（设计师指定：不做模拟）。

> ⚠ **这条是本次改动最需要试玩验证的地方**：8-10 岁孩子真实的挫败容忍度，
> 以及「死了之后会不会看情报、还是直接烦躁退出」。大人算不出这个数。

### 选项代价必须可见（硬约束二的边界）

硬约束二「不能有看起来像陷阱的选项」，在 D&D 式扣血下的边界如下：

| 允许 | 不允许 |
| --- | --- |
| 「打开宝箱（限时答 3 题，**全错扣 7% 最大 HP**）」 | 「打开宝箱」→ 选完才告诉你要扣血 |
| 「走上岔路」→ 遭遇战，扣血 | 「走上岔路」→ 无任何暗示却直接致死 |
| 高代价、高风险的选择 | 暗雷式惩罚 |

**可以代价高昂，不可以是暗雷。** 孩子事后要能说「我知道会有危险，我赌了」，而不是「我被骗了」。

## 一、属性系统

### 1.1 四维属性

| 属性 | 作用 | 换算 |
| --- | --- | --- |
| **力量** | 物理攻击力 | 1:1（1 点 = 1 点伤害） |
| **智力** | 魔法攻击力 | 1:1 |
| **体力** | 生命上限 | 1:1（1 点 = 1 HP） |
| **运气** | 答错后重试概率 | 1-100，见 1.2 |

**Lv1 初始值**：力量 5 / 智力 5 / **体力 10** / 运气 1

体力 = HP（1:1），所以 Lv1 是 **10 HP**。开局偏硬，靠升级把体力拉起来才能求生。这与重生题材相符，设计师已接受开局偏硬（见 B5）。

**为什么力量和智力都要**：它们不是两个数值，是**两种攻击方式**。每个敌人有物理弱点或魔法弱点（由种族标签决定，见 1.11），选对了造成克制伤害（×1.5）。这样：

* 力量流和智力流都成立，不是「哪个数字大用哪个」
* **「克制伤害」有了落点**——克制不是抽象属性，就是「该用剑还是该念咒」
* 题还是那道题，但**打之前要多想一步**（这怪怕什么？委托和谜题里有提示吗？）

### 1.2 运气曲线（1-100）

答错之后，有概率**不扣血、直接重试一次**（运气值越高概率越大）。

**曲线规则（设计师确认）**：运气 1-10 点，触发率与运气点数 1:1（每点 1 个百分点）；从 11 点起开始衰减，曲线平滑，运气 100 点时触发率为 40%。

```
L ≤ 10：  r(L) = L
L > 10：  r(L) = 10 + a × ln(1 + (L - 10) / a)，其中 a ≈ 15.76（使 r(100) = 40%）
```

| 运气 | 触发率 | 每点边际（近似） |
| --- | --- | --- |
| 1 | 1.0% | 1.00 |
| 10 | 10.0% | 1.00 |
| 11 | 11.0% | 0.94 |
| 15 | 14.3% | 0.76 |
| 20 | 17.7% | 0.61 |
| 30 | 22.9% | 0.44 |
| 40 | 26.8% | 0.34 |
| 50 | 29.9% | 0.28 |
| 70 | 34.7% | 0.21 |
| 100 | 40.0% | 0.15 |

**两个要点**：

1. **加点甜区在 10 点以下**：1:1 换算，每点实打实 1 个百分点。
2. **运气要升到很高的等级才用得满**：初始运气只有 1，每级 5 点自由分配（升级制，见 1.4）；运气到 100 需要 99 点，每级 5 点全加运气约需升到 21 级。玩家等级上限 999，可以反复刷任务升级，经验追得上（见 1.4）。

> **A2 的弱点倒计时与运气曲线的关系**：运气触发「答错免伤」，倒计时触发「弱点双倍伤害」。
> 两者独立，互不干扰。运气是容错保护，倒计时是操作奖励。
>
> **倒计时总时长（设计师确认）**：总时长 = 该年级题目的中位耗时 × 1.5，弱点触发率约 28%，
> 「×2 伤害」仍是操作奖励，不是默认收益。各年级总时长暂用 1.10 中鹦鹉表里的默认值（2 年级 13 秒、3 年级 23 秒、4 年级 42 秒），试玩后再调整。

### 1.3 伤害与生命

**答对一题 = 造成一次伤害**：

```
伤害 = 攻击力（力量或智力，1:1）
克制：弱魔法的敌人受到魔法攻击，或弱物理的敌人受到物理攻击 → 伤害 × 1.5
倒计时弱点攻击（总时长一半内答对，见 A2）→ 伤害 × 2（敌人无弱点时同样生效）
两者同时成立 → 相乘（× 3）
伤害出现小数时，四舍五入到整数
```

**敌人的 HP 与攻击力由属性决定**：体力 1:1 等于 HP；攻击力按敌人的攻击系计算，公式见 1.11。

**单座副本题量**：由敌人 HP 与玩家攻击力决定，靠试玩校准（见 B3）。

**答错扣血**：玩家答题错误，受到当前战斗敌人攻击力的伤害，小怪、精英、BOSS 同样适用（设计师确认）。

这是有意的设计：玩家可以升级，地下城里的敌人不会升级，所以打得过；后续还会增加装备系统，提供额外属性。

**机关陷阱**：事件生成时随机决定答错扣多少血（玩家 HP 上限的 5%-10%，四舍五入取整），并在选项上提前显示；答错后仍然继续前进。

**营地**见 3.1，**装备陷阱**见 3.8。

> HP 上限 = 体力属性值（Lv1 为 10）。

> ⚠ 题量、Lv1 仅 10 HP 的容错都是**配平起点，不是结论**，必须靠试玩调——8 岁孩子能承受的题量和挫败感只能实测。

### 1.4 属性点从哪来

**升级制**：杀死敌人和完成任务获得经验，**等级 × 100 = 升到下一级所需经验**，每级奖励 5 点自由分配。玩家等级上限 **999 级**。

敌人经验 = 基础经验 + 世界危险等级 Lv × 系数（设计师指定）：

| 来源 | 基础经验 | 系数（每 Lv） |
| --- | --- | --- |
| 小怪 | 5 | 5 |
| 精英怪 | 20 | 50 |
| 关底 BOSS | 100 | 100 |

例如 Lv3 的小怪给 5 + 3 × 5 = 20 经验。

任务完成经验 = （世界危险等级 Lv + 1）× 档位系数（设计师指定）：

| 来源 | 档位系数 |
| --- | --- |
| D 级任务完成 | 20 |
| C 级任务完成 | 50 |
| B 级任务完成 | 100 |
| A 级任务完成 | 400 |
| S 级赏金任务完成 | 500 |

例如 Lv1 的 C 级任务完成给（1 + 1）× 50 = 100 经验；Lv3 的 S 级赏金任务完成给（3 + 1）× 500 = 2000 经验。

**重生不清零属性**——孩子已得到的成长保留，只有记忆（情报）在新的轮次里更有用。

> **一个后果（设计师已接受）**：属性永久保留且可持续累积 → 等级越高，体力越多，死亡率越低。
>
> 同一危险等级内的任务，玩家等级越高越轻松，接受「后期就是更轻松」。

### 1.5 难度判断

任务卡展示任务档位（D/C/B/A，以及 S 级赏金）和报酬，另有难度标签（见 3.9）；人物页显示当前等级和四维属性值。

```
悬赏：谷仓里的黑影
档位：C 级
标签：旗鼓相当
报酬：100 金币 + 100 经验

你：等级 2    力量 5 / 智力 5 / 体力 15 / 运气 1
```

难度标签保持一维比较：**玩家等级 vs 任务敌人等级**，不含克制关系（克制标签默认看不到，见 1.11），一眼能懂。规则：玩家等级比敌人等级高 4 级及以上，标「轻松应付」；两者相差 3 级以内（含 3 级），标「旗鼓相当」；玩家等级比敌人等级低 4 级及以上，标「满地找牙（困难）」。

玩家靠三层信息判断「我打不打得过」：

| 层次 | 内容 | 谁能看到 |
| --- | --- | --- |
| 第一层 | 任务档位 + 报酬 | 所有人 |
| 第二层 | 委托人描述里的线索（如「啃木头」→ 草食、怕火） | 所有人，但要会读 |
| 第三层 | **「我在这里死过」** 及当时留下的情报 | 死过一次之后 |

**第三层是重生机制和核心玩法的交汇点。** 死亡在这里不是惩罚，是**花一条命买情报**。

### 1.6 配平

不做模拟（设计师指定）。死亡率、单座题量、敌人强度都靠试玩观察和调整，文档里不保留死亡率数字。

### 1.7 死亡归因（这条决定死亡是否「教会东西」）

死亡来自两类：战斗答错，以及决策（机关陷阱、装备陷阱）。这符合 ★ 节的「死亡必须教会东西」：死亡要落在孩子**能改变的选择**上（解不解谜题、开不开宝箱），而不是「你数学不好所以死了」。两类各占多少，靠试玩观察。

### 1.8 谜题的价值

每座地下城有 2 个 BOSS 谜题：解开一个揭示 BOSS 的弱点标签，解开另一个获得一件可在 BOSS 战使用的故事道具（详见 3.4）。没解谜题但猜对了弱点，同样造成克制伤害；用弱点打中敌人后，标签自动揭晓。具体降幅靠试玩观察。

### 1.9 装备

装备有五个来源：营地（3.1）、装备陷阱（3.8）、NPC 事件（3.5）、黑市商人购买（3.5、3.11）、狗的「嗅觉」（1.10）。

**装备部位（设计师指定）**

玩家控制的角色可以装备的部位：头、胸、腿、脚、手、项链、以及 5 个手指部位，每个手指部位可以各佩戴 1 个戒指。装备要对应这些部位。

**装备属性（设计师指定）**

| 品质 | 提供的属性点 | 词条 |
| --- | --- | --- |
| 白色 | 世界危险等级 Lv + 0 到 5 的随机整数（整数随机）作为属性点 | 没有 |
| 蓝色 | 世界危险等级 Lv × （1.5 - 2）+ 5 的随机属性点 | 默认带 1 个 |
| 黄色 | 世界危险等级 Lv × （3 - 4）+ 10 的随机属性点 | 默认带 2 个 |

属性点随机分配到力量、智力和体力上。蓝色和黄色的倍数在区间内连续随机取值，算出的属性点按四舍五入取整（设计师指定）。词条库计划 2026-10-10 建立，目前先占位。还没定的细节见 B12。

**装备部位的确定（设计师指定）**

装备在获得时随机决定部位，5 个手指部位各算一个独立部位，随机时每个部位的概率相同。

- 白色装备：50% 的概率只在没有穿戴装备的部位中选，其余情况在全部部位中随机；全部部位都已穿戴时，等于纯随机。
- 蓝色、黄色装备：品质按颜色区分（白 < 蓝 < 黄）。60% 的概率只在已穿戴装备品质比它低的部位中选（没有穿戴装备的部位算品质最低），其余情况在全部部位中随机；没有这样的部位时，等于纯随机。

**装备掉落后的处理（设计师指定）**

- 掉落的装备都进背包，不会自动穿上。
- 是否替换身上的装备，由玩家自己比较装备好坏后决定，游戏不判断哪件是垃圾装备。
- 不需要的装备，回到城镇后可以在道具商人处卖出，价格是黑市同品质装备售价的 1/10（见 3.11）。只有背包里的装备可以卖，身上已穿戴的装备不能卖。

**各来源的装备品质概率（设计师指定）**

| 来源 | 品质概率 |
| --- | --- |
| 营地「获取装备」 | 白色 70%，蓝色 25%，黄色 5% |
| 装备陷阱（答对 3 题） | 蓝色 80%，黄色 20% |
| NPC 救助（奖励为装备时） | 白色 70%，蓝色 30% |
| 黑市商人（一次展示 3 件） | 白色 50%，蓝色 30%，黄色 20%，每个槽位独立概率 |
| 狗的「嗅觉」额外装备 | 白色 |

### 1.10 五个种族

**选择种族（设计师指定）**

- 新游戏时先自动使用一个空白存档位，再进入种族选择界面；选好后进入城镇（见第五节开始页）。
- 选定后不能更换种族；以后游戏里可能提供更换功能，先占位。
- 角色不能起名，默认用种族动物的英文名作为名字：熊 Bear、猫 Cat、鳄鱼 Crocodile、鹦鹉 Parrot、狗 Dog。

设计原则：每个种族都有只属于它的能力，都能通关；差异是玩法，不是强弱；玩家种族之间不设克制（对 8 岁孩子，「我选的族更强」比「策略平衡」重要）。

| 种族 | 能力 | 机制 | 频次 |
| --- | --- | --- | --- |
| **狗** | 嗅觉 | 每次成功获得装备后（营地、装备陷阱、NPC 事件、黑市购买都算），独立 10% 概率判断是否额外获得一件白色装备；额外的白色装备本身不会再触发判断；成功后，到下次住酒店休息前不再发动；失败的话，之后每次获得装备再判断一次 | 每次住酒店休息后恢复，两次住酒店之间最多发动 1 次 |
| **熊** | 厚皮 | **受到的伤害 -2 点**；在按敌人攻击力和百分比扣血的规则下同样生效，减免后最低扣 0 点（设计师确认不强大） | 常驻 |
| **猫** | 智力 +5 | 智力 5 → 10（魔法攻击力翻倍） | 常驻 |
| **鳄鱼** | 死亡翻滚 | 面对敌人题目时，可直接造成**力量 × 3 = 15** 伤害 | 每次住酒店休息后恢复 1 次 |
| **鹦鹉** | 灵敏反应 | **答题时间额外 +5 秒** | 常驻 |

> **一场地下城 = 12 小时**（见 2.5）。一天 24 小时 → 每天可打 2 座。
> 种族的「每天一次」能力，在住酒店休息后恢复（设计师指定）。死亡后游戏时间回退，不会让能力恢复。

#### 种族对死亡率的影响

各种族对死亡率的影响靠试玩观察，不保留数字。

#### 各能力的作用维度不同

五族**不是同一维度的差异**，需分开评估：

| 种族 | 维度 | 生效方式 |
| --- | --- | --- |
| 熊 | 生存 | 每次受伤 |
| 猫 | 输出 | 每次攻击（题数减少 25%） |
| 鳄鱼 | 爆发 | 一次（住酒店休息后恢复） |
| 鹦鹉 | 时间 | 每次答题（影响弱点判定） |
| 狗 | 掉落 | 概率触发（每次获得装备时判定，两次住酒店之间最多发动一次） |

**鹦鹉的收益随题目难度递减**（+5 秒是固定值）：

| 年级（世界危险等级） | 题例 | 总时长 | 鹦鹉后 | 弱点率变化 |
| --- | --- | --- | --- | --- |
| 2 年级（Lv1-Lv5） | 47+38 | 13s | 18s | 28% → **53%**（+25pt） |
| 3 年级（Lv6-Lv10） | 234×3 | 23s | 28s | 28% → 43%（+15pt） |
| 4 年级（Lv11-Lv20） | 234×27 | 42s | 47s | 28% → 36%（+8pt） |

（假定总时长 = 该年级题目的中位耗时 ×1.5，弱点窗口 = 总时长一半。4 年级的较难题（Lv16-Lv20，含应用题）的总时长未估算。）

年级越高，鹦鹉的收益越小。

#### 能力维度覆盖：目前集中在战斗数值

五族的能力全部落在战斗数值维度，下列维度暂无种族能力呼应：

| 维度 | 举例 | 现状 |
| --- | --- | --- |
| 决策 | 遭遇战可选择逃跑 | 无 |
| 数学容错 | 每场战斗排除一个错误答案 | 无 |
| 情报/推理 | 接任务前看到完整情报 | 无 |
| 地图探索 | 钻进窄通道，开启独占路线 | 无 |

**连带影响**：谜题与真相（见 3.4）依赖玩家解谜题。没有任何种族能力奖励「获取情报」，解谜题只有剧情和弱点收益，无种族能力与之呼应。这些维度先不补，占位（设计师指定）。

### 1.11 敌人种族与属性成长

每个敌人属于一个种族。敌人和玩家一样有力量、智力、体力三项属性（见 1.1），体力 1:1 等于 HP。种族决定属性成长的偏向、攻击系和克制标签。每座地下城里出现什么种族的敌人，由这座地下城的故事情节决定。

**基础值（设计师指定）**

1 级敌人有默认的基础属性：

| 敌人类型 | 默认力量 | 默认智力 | 体力（随机） |
| --- | --- | --- | --- |
| 小怪 | 1 | 1 | 3-5 |
| 精英 | 2 | 2 | 4-8 |
| BOSS | 3 | 3 | 10-20 |

**属性成长（设计师指定）**

| 敌人类型 | 每级获得的属性点 |
| --- | --- |
| 小怪 | 2-3 点（随机） |
| 精英 | 4-5 点（随机） |
| BOSS | 6-8 点（随机） |

**分配规则（设计师指定）**

- 每级获得的点数里，50%-60% 分给种族的主加属性，四舍五入取整。
- 其余点数随机分配给另外两项。
- 从 1 级起每级都随机分配。
- 力量和智力不能同时为 0（有了基础值，实际不会出现）。

敌人等级为 L 时：属性 = 基础值 + L 次随机分配的点数。累计分配的点数：小怪 2L 到 3L 点，精英 4L 到 5L 点，BOSS 6L 到 8L 点。

**攻击力（设计师指定）**

敌人的攻击力按主加属性计算：

| 主加属性 | 攻击力 |
| --- | --- |
| 力量（物理系） | 力量 × 1 + 智力 × 0.2 |
| 智力（魔法系） | 力量 × 0.2 + 智力 × 1 |
| 体力 | 力量 × 0.5 + 智力 × 0.5 |

攻击力出现小数时，四舍五入到整数。

主加力量归物理系、主加智力归魔法系（设计师确认）。

- 敌人带有克制标签：弱魔法、弱物理，或无弱点。无弱点也是一种标签，种族可以没有弱点。目前上表中没有无弱点的种族。
- 标签先跟着种族走，上表的对应关系已采用；未来预留修改标签的空间，具体方式届时再定。
- 克制时造成 1.5 倍伤害，与倒计时弱点攻击（×2）相乘，见 1.3。敌人无弱点时，倒计时弱点攻击仍然生效。

- 编写 BOSS 的线索故事时，情报按它的种族标签来。

## 二、死亡与重生

### 2.1 提示机制与错题小结页（你最看重的一条）

**死亡后先出现错题小结页（设计师指定）**：死亡后，先出现一页错题小结，列出本次死亡中所有答错的题，每道题给讲解和正确答案。系统同时记下 `{副本, 场景, 题目}` 和题型。

**提示的出现时机（设计师指定）**：提示不是随便给的。只有死亡之后，重生再遇到这个题型的新题时，题目下方才出现提示。第一次只给解题思路，不给答案；第二次及以后在同类型题目死亡，都给解题步骤和答案（见 2.2）。看了提示答对，伤害照常。

> 石门上浮出符文：
>
> **47 + 38 = ?**
>
> 💡 你记得上次是怎么卡住的：
>
> 先算十位 40+30=70，再算个位 7+8=15，最后 70+15。
>
> `[ 60 ]  [ 75 ]  [ 85 ]  [ 95 ]`

孩子看完这一步，基本就能自己算出来了——**这正是你要的效果**，也是「提示」和「给答案」的分界线。

### 2.2 同一题型再次死亡，给的内容更多

同一个题型再次死亡，提示给得更多（设计师指定）：

| 死法 | 给什么 |
| --- | --- |
| 第一次死在这个题型 | 死亡后先出现错题小结页，给讲解和正确答案；重生后遇到同类新题，题目下方给**解题思路**，不给答案 |
| 第二次及以后死在同一题型 | 每次都给**解题步骤 + 答案**。下次遇到的是新题，所以给答案没有关系 |

### 2.2b 提示绑「这道题」还是「这个题型」（A8）

这是提示机制**成败的关键**，也是最容易做错的一处。

孩子死在那道题上，是 `47 + 38`。重生后遇到的是**同类的新题**（换了数字，如 `56 + 27`）。真正的考验是：提示还在不在？

| 做法 | 结果 |
| --- | --- |
| 只绑 `47+38` 这一道 | 孩子**只会这一道**，换个数字又卡住 → **没有学习迁移**，提示沦为过关工具 |
| **绑题型「两位数进位加法」** | 孩子学会的是方法，换数字也会 → **这才是真正的学习** |

**绑题型，提示内容用具体题目演示：**

> 第一次死在这类题 → 错题小结页用具体题目（`47+38`）完整讲解，并给正确答案
>
> 重生后遇到同类新题 `56+27` → 题目下方给解题思路，不给答案：
>
> 💡 你学过这种题：先算十位，再算个位，最后加起来。
>
> 第二次及以后死在这类题 → 给解题步骤和答案

**这样才把「错题复习」和「提示」接成一件事**——「答错过的题型，重生后会再出现同类新题」（见 2.4），它就从「再考你一次」变成「再教你一次」。

> ⚠ 代价要说清：绑题型意味着**要维护「题型」这个概念**（如「两位数进位加法」「表内乘法」），
>
> 题库得给每道题打题型标签。这会让 `src/math.js` 稍微复杂一点，但换来的是真正的学习迁移。

### 2.3 这条机制为什么是对的

**主题上**：重生题材的核心是「我记得上次为什么死了」。而**这道题的提示，就是那段记忆本身**。机制和叙事在这里是同一件事——不是一个系统加一个皮肤。

**教学上**：这是标准的**脚手架（scaffolding）**——孩子卡住时给支撑，会了就撤掉。比「再出十道同类题」有效得多，而且孩子不会觉得自己在被罚。

**情绪上**：死亡从「我输了」变成「**我知道了**」。孩子会主动想去看看那道题现在给什么提示。

### 2.4 重生清空什么

| 清空 | 保留 |
| --- | --- |
| 本次地下城中获得的所有收获（金币、装备、道具等） | **全部记忆**：四维属性、死过副本的记录、题目提示；非本次地下城所得的金币、装备、道具 |

> **属性不清零**（2026-10-08 定）。死亡丢失本次地下城中的所有收获，非本次地下城所得保留（设计师指定）；等级、属性点、经验按原有决定全部保留。

**记忆在游戏里的三种用法**：

1. 死过的副本在地图上标出：「我在这里死过 · 被梦魇守卫打退的」
2. 已揭晓的敌人克制标签一直显示
3. **答错过的题型，重生后会再出现同类新题（换数字）**——刻意的间隔复习，配合 2.1 的提示，让「重来一次」不只是游戏机制，而是真的把题做会了

**轮回数当徽章**：主界面显示「第 N 次人生」。孩子会主动跟人说「我已经活到第 7 次了」。**不做 Game Over 画面，不做嘲讽文案。**

### 2.5 一趟冒险的完整循环

**地下城不是一口气连着打的。** 一趟只打一座，然后回城。

**时间单位：一场地下城 = 12 小时。** 一天 24 小时 → **每天可打 2 座**。种族的「每天一次」能力在住酒店休息后恢复（设计师指定）。

```
小镇（接任务）
   ↓
地下城（读剧情，触发事件；至少 3 场战斗：小怪 → 精英 → BOSS，BOSS 战前一定有营地）
   ↓
回城 · 交任务（拿报酬和经验）
   ↓
休息（住酒店：付金币回血、存进度，睡到第二天早上 6:00）
   ↓
看悬赏板，接下一个任务 ←──┐
   ↑                       │
   └───────────────────────┘
```

**为什么这样设计**：

| 好处 | 说明 |
| --- | --- |
| **单次时长可控** | 一座 10-15 分钟，适合 8-10 岁孩子的注意力 |
| **每座独立结算** | 难度只需按**单座**配平，不用考虑「连打多座」的累积压力 |
| **死亡不等于白玩** | 死在地下城里，等级、属性、经验和记忆都保留，只是这次任务没完成，本次地下城的收获会丢失，游戏时间回退到进入地下城之前。死亡后自动回到城镇墓地，只有 10% 最大 HP，要去酒店休息 |
| **有自然的休息点** | 住酒店是明确的「今天到此为止」信号，家长也好管理 |

**住酒店（设计师指定）**：住一晚，第二天早上 6:00 起床，同时存档。有两档：花 1 金币回复 20% 最大 HP，花 5 金币回复 100% 最大 HP。

**死亡后（设计师指定）**：在地下城里死亡，自动回到城镇墓地，血量默认只有 10% 最大 HP，要去酒店休息。游戏时间回退到进入地下城之前（符合重生概念）。任务板不随游戏时间回退，已刷新的任务保持不变，回退后再次经过早上 6:00 也不会再刷新（设计师指定，影响小）。种族能力不会因为时间回退而恢复，必须住酒店休息后才恢复。重生时如果玩家一分钱也没有，自动给 10 金币。

**城镇（设计师指定）**

- 城镇用 2D 俯视角像素风格呈现，类似 GameMaker 做的 2D 俯视角游戏，整体风格偏暗黑。
- 城镇里有冒险公会、酒店、道具商人、墓地和教堂。教堂先用图片占位。
- 玩家用方向键（上下左右）或点击鼠标走路。

**游戏时间（设计师指定）**

- 城镇画面顶部有一个时钟，格式为 00:00，每过现实 1 秒跳动一次（游戏时间 1 分钟），界面上不加解释文字。地下城里不显示时钟（见 3.14）。
- 新游戏从早上 6:00 开始。
- 在城镇里，时间正常流逝。
- 住酒店时，时间加速流逝到第二天早上 6:00；在 0:00 到 6:00 之间住酒店，醒来是当天的 6:00。
- 地下城通关，或在营地离开地下城，游戏时间都直接加 12 小时，与实际用时无关。
- 地下城的 12 小时跨过早上 6:00 时，回城后任务板和道具商人补刷新一次。
- 地下城的进度不受早上 6:00 刷新影响，只在死亡或在营地离开地下城时重置。
- 每天早上 6:00 刷新任务（见 3.9）。

## 三、地下城与悬疑剧本

每座地下城是一个独立的悬疑剧本，套同一个三段式战斗骨架。

### 3.1 战斗与数值

一座地下城至少有 3 场战斗，按小怪、精英、BOSS 的顺序安排（设计师指定）。其余事件见 3.5。下表是每场战斗的敌人数量和扣血规则。

| 战斗 | 敌人数量 | 答错扣血 | 设计作用 |
| --- | --- | --- | --- |
| **小怪战** | 1-4 只，随机 | 受到该小怪的攻击力伤害 | 建立信心、教机制 |
| **精英战** | 1-2 只，随机 | 受到该精英的攻击力伤害 | 第一次真风险，确认真相 |
| **BOSS 战** | 固定 1 只 | 受到该 BOSS 的攻击力伤害 | 挑战、收束 |

数学题的年级按世界危险等级出，见 3.3。

各场战斗敌人的 HP 和攻击力由属性决定（见 1.11），题量靠试玩校准（见 B3）。

**营地**：营地是一种事件（见 3.5），在 BOSS 战前一定出现一次（设计师指定）。营地有三个选项，只能选其中一个（设计师指定）：

| 选项 | 效果 |
| --- | --- |
| 回复血量 | 回复 30% 最大 HP |
| 获取装备 | 获取一件装备，品质：白色 70%，蓝色 25%，黄色 5% |
| 离开地下城 | 主动离开，离开后这座地下城的进度重置；已获得的金币、装备、道具保留，包括针对 BOSS 的故事道具；任务仍处于接取状态；重新进入后从头过一遍剧情，已完成的事件（包括战斗）不再进行，只显示一句提示，告诉玩家这里已经完成、继续前进；营地每次进入都会出现，但以前选过的选项不能再选，只有历次都没选过的选项可用；三个选项都选过后，营地仍然出现，但只有「继续前进」可选；离开时游戏时间加 12 小时（设计师指定） |

营地不只是数值配平，是**给孩子一个喘息和一个决定**：这里可以主动离开地下城。离开不算死亡，已获得的收获保留，地下城进度重置，任务仍处于接取状态。**给出口比给难度重要**。

### 3.2 一局的节奏

```
进城 → 看悬赏（档位 + 报酬 + 难度标签）
  → 读剧情，触发事件（按故事安排，见 3.5）
     战斗（至少 3 场，按小怪、精英、BOSS 顺序）
     谜题、营地（BOSS 战前一定出现，可选择离开地下城）、黑市商人（由故事情节决定）、获取装备、剧情选择（分支路线、守卫盘问、机关陷阱）、NPC 救助、日记或信件
  → BOSS 战（非战斗解法为占位，暂不实现）
  → 回公会领报酬
```

**一趟 10-15 分钟。**

### 3.3 难度与出题呈现

题库按年级分，**年级由世界危险等级决定**，不需要家长设置。战斗、谜题、装备陷阱的数学题，都按当前危险等级对应的年级出：

| 世界危险等级 | 敌人等级 | 数学题 |
| --- | --- | --- |
| Lv1-Lv5 | 1-25 级 | 2 年级 |
| Lv6-Lv10 | 26-50 级 | 3 年级 |
| Lv11-Lv15 | 51-75 级 | 4 年级基础题 |
| Lv16-Lv20 | 76-100 级 | 4 年级较难题，含应用题 |

各年级的题型（设计师指定：题目只需符合年级，和事件、战斗结合即可，不按怪物类型区分题型）：

| 年级 | 题型 |
| --- | --- |
| 2 年级 | 100 以内加减，表内乘法，两位数加减 |
| 3 年级 | 表内乘法，多位数 × 一位数，除数是一位数的除法 |
| 4 年级 | 多位数 × 一位数，三位数 × 两位数，四则混合 |

4 年级基础题（Lv11-Lv15）与较难题（Lv16-Lv20，含应用题）的题型草案，参考澳洲 ICAS 数学考试 Year 4 的五个考查方向整理，**建议（待确认）**：

| 考查方向 | 基础题（Lv11-Lv15） | 较难题（Lv16-Lv20，含应用题） |
| --- | --- | --- |
| 数与算术 | 多位数加减，多位数 × 一位数，除数是一位数的除法 | 两步或三步的四则混合应用题 |
| 代数与规律 | 补全数列，找出数列规律 | 求数列中指定位置的数，含未知数的算式 |
| 测量 | 长度、质量、容量的单位换算，读时间 | 周长和面积的应用题，时间差应用题 |
| 空间与几何 | 认识平面图形和立体图形，对称 | 组合图形的周长，简单的方位和路线 |
| 机会与数据 | 读简单的条形图和表格 | 综合读图并计算，比较可能性大小 |

考查方向的来源是 ICAS 官网对 Year 4 数学的介绍，只参考了方向，没有使用真题。目前没有具体题目，草案等有题后再审核；草案与上面 4 年级一行如何合并，见 D1。

**年级内的难度由孩子自己的表现决定：连续答对 3 题升档，答错 2 题降档**（硬规则，不靠猜）。升降档只在当前年级的题目里增减难度，不跨年级。**目标答对率 60-80%**：太简单会无聊，太难会放弃。

**呈现方式：不能像作业。** 包在叙事里，而且要短：

> 石门上浮出符文，数字在发光：
>
> **47 + 38 = ?**
>
> 算对了，门就会开。

- **4 选 1，不做数字键盘输入**（低龄输入太慢，挫败感强）
- 干扰项要「合理」：来自典型错误（进位忘了、数位对错），不能乱写
- 每题只占一屏的三分之一，永远不遮住剧情
- 每屏正文 ≤60 字，短句，关键词高亮

**出题时机**：战斗（念咒语、放技能，算对造成伤害）、解谜（开石门、破暗号，算对推进剧情）、交易（买东西算找零，可选）。

**答错 ≠ 死。** 单题答错只扣血，死亡是累积结果：

| 场景 | 答错后果 |
| --- | --- |
| 战斗中 | 敌人反击，**扣血但战斗继续**，可以再答（运气可能让这次免伤重试，见 1.2） |
| 解谜中 | 暂时打不开，**可以换条路，或先去探索别处** |
| 交易中 | 多花钱，不影响生死 |

理由：8-10 岁的孩子会把「数学题答错」和「我数学不好」直接连起来。如果答错就死，这个游戏会变成**数学焦虑训练器**。

### 3.4 谜题与真相：悬疑必须能兑换成战斗优势

**如果只保留一条设计判断，保留这条。**

儿童游戏最容易犯的错，是把推理做成「读文字 → 猜答案 → 猜对给奖励」。孩子很快会学乖：**跳过所有文字，直接莽进去打，反正打不过再来一次**。这样悬疑剧本就只是装饰。

**所以：推理必须直接帮到战斗。**

悬疑线索做成谜题。BOSS 谜题每座地下城固定 2 个（设计师指定）：一个揭示 BOSS 的弱点标签，一个给故事道具。谜题是数学题，包在一个小故事里，这个小故事揭晓 BOSS 的一部分情报，每个谜题各揭晓真相的一部分。

编写线索故事时，BOSS 的情报要按它的种族标签来（见 1.11）。例如 BOSS 的种族是弱物理，故事就要指向它怕物理。

**数学题难度与世界危险等级挂钩**：战斗、谜题、装备陷阱的数学题都按当前危险等级对应的年级出，对应关系见 3.3。

**解开一个谜题的收益**

| 收益 | 内容 | 状态 |
| --- | --- | --- |
| 揭示 BOSS 弱点标签 | 两个 BOSS 谜题中的一个。解开后，BOSS 的克制标签显示出来 | 已定 |
| 故事道具 | 两个 BOSS 谜题中的另一个。解开后获得一件可在 BOSS 战使用的故事道具。它会直接出现在对敌人的攻击选项里，点击即可使用，不用做题；效果和鳄鱼的「死亡翻滚」一样，直接造成伤害。例如直接扣除 BOSS 50% 血量。对 BOSS 使用后就消耗掉；在营地主动离开地下城时保留，其他情况下离开地下城后失效；死亡后重来，事件全部重置，按同样流程可以重新获得同样的故事道具 | 占位，未来可扩展 |

| 情况 | 效果 |
| --- | --- |
| 解开一个 BOSS 谜题 | 得到上表中对应的收益 |
| 没解谜题 | 弱点标签默认看不到。提前猜到弱点，同样造成克制伤害（×1.5）；猜错没有任何加成 |
| 用弱点打中敌人 | 标签自动揭晓，此后一直显示，按种族揭晓 |

精英和小怪的标签只能靠用弱点打中来揭晓，谜题只揭露 BOSS 的弱点。

**非战斗解法（占位）**：不用打死 BOSS 的解决方式，例如范本里给受伤的狮鹫包扎喂食，或把做梦的古树叫醒。先占位，不参与具体实现。

### 3.5 故事与事件序列

每座地下城是一个故事，用冒险书的方式呈现：玩家读一段剧情，然后出现一个事件。

**故事三要素（设计师指定）**：好莱坞编剧常用的剧本三要素，英文都以 C 开头。

| 要素 | 含义 |
| --- | --- |
| Character 人物 | 有欲望、有缺陷的主角 |
| Conflict 冲突 | 阻碍主角达成目标的阻力 |
| Change 转变 | 故事结尾，人物或局面发生改变（人物弧光） |

故事就是剧情，不涉及数值。写好故事之后，用它来指导具体敌人和谜题的分析（见 3.10）。

**事件规则（设计师指定）**

事件可以是敌人战斗、谜题或其他选择题。

- 至少有 3 场战斗，按小怪、精英、BOSS 的顺序安排。
- 营地在 BOSS 战前一定出现一次。
- 地下城有分支事件：玩家可以选择不同路线前进，选路线本身没有惩罚。分支路线放在剧情选择里，需要符合剧情展开逻辑（设计师指定）。
- 每个事件有各自独立的答题倒计时，例如装备陷阱 3 题共用 40 秒；营地、黑市商人这类事件没有计时器（设计师指定）。
- 离开地下城后重新进入同一座地下城，从头过一遍剧情：已完成的事件（包括战斗）不再进行，只显示一句提示，告诉玩家这里已经完成、继续前进；没完成的事件照常进行。营地是例外，每次进入都会出现；营地的三个选项，以前进入时选过的不能再选，只有历次都没选过的选项可用；三个选项都选过后，营地仍然出现，但只有「继续前进」可选（设计师指定）。
- 死在地下城后重新挑战，事件全部重置，选项也重置，数学题重新出题（设计师指定）。
- 其余事件从下表安排。

**事件数量（设计师指定）**：事件总数由任务档位决定，含战斗：

| 任务档位 | 事件数量 |
| --- | --- |
| D 级 | 5-8 个 |
| C 级 | 6-9 个 |
| B 级 | 7-11 个 |
| A 级 | 8-12 个 |
| S 级 | 10-15 个 |

各档位任务（D 到 S 级）在其他事件里，都允许增加 1-2 场小怪或精英战斗，额外增加的战斗不会出现 BOSS 级别（设计师指定）。额外战斗放在事件序列的什么位置，基于故事情节编排安排。事件数量只算事件，不算纯剧情段落。

| 事件 | 内容 |
| --- | --- |
| 战斗 | 小怪战 1-4 只（随机），精英战 1-2 只（随机），BOSS 战固定 1 只，数值见 3.1 |
| 营地休息 | BOSS 战前一定出现一次；三选一：回复 30% 最大 HP、获取一件随机装备、离开地下城（地下城进度重置，已获得的收获保留，任务仍处于接取状态；重新进入后已完成的事件只显示已完成的提示，营地每次进入都会出现，但历次选过的选项不能再选），见 3.1 |
| 黑市商人交易 | 是否出现由故事情节决定，情节里不适合放商人就没有商人。出现时一次展示 3 件装备和 2 个血瓶，卖完就没了。用金币购买，没有数学题，商品和价格见 3.11 |
| BOSS 谜题 | 解开谜题揭示 BOSS 的弱点，并获得故事道具，见 3.4 |
| 获取装备 | 要完成数学题。可能来自 NPC 事件；装备陷阱（3.8）是获取装备的一个事件类型 |
| 剧情选择 | 玩家在剧情里做选择，选项上要提前写明代价（硬约束二）。有下面三个子类型 |
| 剧情选择·分支路线 | 玩家选不同路线前进，没有答题，没有惩罚 |
| 剧情选择·守卫盘问 | 答对数学题才放行。答错可以重答，或离开走别的路线，没有惩罚 |
| 剧情选择·机关陷阱 | 例如机关门：答对开门，答错扣血但仍然开门。事件生成时随机决定答错扣多少（玩家 HP 上限的 5%-10%），并在选项上提前显示（设计师指定） |
| NPC 救助 | 帮助 NPC。大多数是战斗事件，也可能是机关陷阱。奖励按概率随机：装备 35%（白色 70%，蓝色 30%），血瓶 30%（小血瓶 60%，中血瓶 40%），金币 35%（20-50），见 3.11 |
| 日记或信件 | 只给剧情线索，不战斗，不扣血 |

**写故事的三条纪律**：

1. **红鲱鱼必须存在，但不能刻薄。** 误导性证词要来自「看错了」而不是「撒谎」。孩子不该学会「大人在骗我」。
2. **真相要温柔。** 目标是让孩子心里「哦——原来是这样」，而不是「我被耍了」。
3. **每个谜底都要能一句话说清。** 讲不清，就是设计得太绕了。

### 3.6 两座范本（按故事三要素整理）

> 两座范本沿用原有的剧情素材，按 3.5 的三要素和事件规则重新整理，作为故事框架（设计师确认）。具体变成故事时，还要丰满和合理化。范本里各有 3 条线索，具体变成故事时，按 3.4 整理为 2 个 BOSS 谜题（一个揭示弱点，一个给故事道具）。

#### 范本一：南方农场（怪叫声）

**人物**：农场主老山羊（被怪事逼得说要卖地）；证人小羊羔、路过的货郎；受伤的幼年狮鹫。

**冲突**：夜里有怪叫，奶牛挤出的奶发酸，母鸡不下蛋。三个证人说法互相矛盾：

| 证人 | 说法 | 真假 |
| --- | --- | --- |
| 农场主老山羊 | 「是鬼。我听过，像人在哭。」 | 看错了 |
| 小羊羔 | 「不是鬼。叫声有规律的，隔一阵一次，像在打呼噜。」 | **对** |
| 路过的货郎 | 「我看见一团大影子往北飞走了！」 | 看错了（是猫头鹰） |

**转变**：真相揭开后，大家发现狮鹫什么都没干，它只是在养伤睡觉。长得凶不等于是坏的。

**事件序列**：

1. 剧情：公会悬赏。
2. 剧情：现场勘查。谷仓外墙有三道平行的深抓痕，位置很高，**比人高**，地上撒着谷物。
3. 剧情：三方证词（见上表）。
4. 谜题：每个谜题是数学题，包在一个小故事里，各揭晓真相的一部分。
   - **抓痕**：三道、平行、很高 → 有爪子，体型大，够得着高处
   - **谷物**：被啃过，但啃得很乱、只啃了一半 → **不是它吃的**，是别的东西在偷吃
   - **叫声**：有节奏、周期重复 → 是**呼吸声**。它在睡觉
5. 战斗·小怪：巨鼠群（1-4 只，随机；僵尸动物），偷饲料的真凶。
6. 战斗·精英：守夜犬（1-2 只，随机；恶魔），被吵醒，**用抓痕的发现可安抚，跳过战斗（非战斗解法，占位，暂不实现）**。
7. 营地休息。
8. 剧情：真相揭示。谷仓顶上藏着一只**受伤的幼年狮鹫**，在养伤。所谓怪叫是它的鼾声。奶变酸是因为巨鼠群被它的气味引来偷吃饲料，惊扰了奶牛。**狮鹫什么都没干，它只是在那儿睡觉。**
9. 战斗·BOSS：幼年狮鹫（狮鹫），**非战斗解法（占位，暂不实现）：包扎伤口、喂食，它成为小镇守护者**。

#### 范本二：东部森林（去了没回来的勇者）

**人物**：三批进森林后没回来的勇者；逃回来的见习骑士、守林人、酒馆老板；森林深处的千年古树。

**冲突**：三批勇者进森林，一个都没回来。公会不再派人，但悬赏还在墙上。三个证人说法各不相同：

| 证人 | 说法 | 真假 |
| --- | --- | --- |
| 逃回来的见习骑士 | 「有东西在树影里追我！我拼命跑才出来。」 | 部分对（他确实被追，但那是梦） |
| 守林人 | 「森林里最近很安静。太安静了。」 | **对** |
| 酒馆老板 | 「那三个人本来就不太行，早就劝他们别去。」 | 无关（红鲱鱼） |

**转变**：真相揭开后，大家发现攻击人的东西其实是在保护自己，勇者们只是被卷进了古树的梦里。看着在攻击你的东西，可能是在保护自己。

**事件序列**：

1. 剧情：公会悬赏。
2. 剧情：现场勘查。森林边缘，倒下的树上有整齐的刻痕，地上没有血迹、没有打斗痕迹。
3. 剧情：三方证词（见上表）。
4. 谜题：每个谜题是数学题，包在一个小故事里，各揭晓真相的一部分。
   - **装备**：勇者的剑和盾整齐靠在树洞里，**没有打斗痕迹，是自己放下的**
   - **甜味**：树洞里有一股甜味，地上有白色树脂 → 千年古树的树脂**有催眠效果**
   - **刻痕**：同一个符号反复刻，但**刻得很整齐、每道深浅一致** → 刻的人还有意识，是**求救**
5. 战斗·小怪：梦里的影子（1-4 只，随机；幽灵），是勇者们的噩梦具象化，打散了噩梦就变淡。
6. 战斗·精英：梦魇守卫（1-2 只，随机；恶魔），古树的自我保护机制，**不是敌人，是免疫系统**。
7. 营地休息。
8. 剧情：真相揭示。森林深处有一株千年古树，它**在做梦**。它梦里的一切会变成真的，靠近的人会被卷进同一个梦。三个勇者都困在梦里，身体还好好的。
9. 战斗·BOSS：古树的梦本体（植物），**非战斗解法（占位，暂不实现）：在梦里找到三个勇者，一起算出唤醒仪式的数字序列，把它叫醒**。

### 3.7 故事素材骨架（待展开）

下面三个故事骨架已按故事三要素整理，作为故事框架（设计师确认），是地下城生产模板的故事素材（见 3.10）。具体变成故事时，还要丰满和合理化，并继续拓展。

### 3.8 装备陷阱（限时答题）

装备陷阱是「获取装备」事件的一个类型（见 3.5）。

装备陷阱也是谜题。每个装备陷阱要在限时内答对 3 道题目，3 题共用一个总时长，目前所有年级都是 40 秒（设计师指定）。按答对的题数决定结果，扣血的基数是玩家最大 HP：

| 答对题数 | 结果 |
| --- | --- |
| 0 题 | 扣血，扣多少在事件生成时随机决定（玩家最大 HP 的 5%-10%，四舍五入取整），不给装备 |
| 1 题 | 不扣血，给 10 金币，不给装备 |
| 2 题 | 不扣血，给 20 金币，不给装备 |
| 3 题 | 不扣血，获取一件装备：80% 蓝色，20% 黄色 |

选项上要提前显示代价：装备陷阱事件生成时，随机决定全错时扣多少血（玩家最大 HP 的 5%-10%），并在选项上提前显示，例如「限时答 3 题，全错扣 7% 最大 HP」（硬约束二，设计师指定）。

### 3.9 冒险公会任务发布

地下城不是固定的几座，而是由冒险公会的任务生成：每个任务对应一座全新的地下城，由地下城生产模板生成（见 3.10）。

**发布规则（设计师指定）**

- 每次发布，随机发布 6-8 个任务：D 级 1-2 个，C 级 2-3 个，B 级 1-2 个，A 级 0-1 个。
- 四档数量范围相加，最少 4 个、最多 8 个。随机结果的总数不在 6-8 个时，重抽，直到落在 6-8 个。
- 每天早上 6:00（游戏时间）刷新。游戏时间 1 分钟 = 现实 1 秒，所以一个游戏日 = 现实 24 分钟；地下城通关或在营地离开后，游戏时间直接加 12 小时，与实际用时无关（见 2.5）。
- 玩家必须回到冒险公会提交，任务才算完成。

**世界危险等级（设计师指定）**

世界危险等级共 20 级。Lv n 对应敌人等级 5(n-1)+1 到 5n 级：Lv1 为 1-5 级，Lv2 为 6-10 级，Lv3 为 11-15 级，依此类推，最高到 Lv20（96-100 级）。同一个任务里，小怪、精英、BOSS 是同一等级。

| 任务档位 | 敌人等级 |
| --- | --- |
| D 级 | 区间第 1 级（Lv1 为 1 级，Lv2 为 6 级） |
| C 级 | 区间第 2 级（Lv1 为 2 级，Lv2 为 7 级） |
| B 级 | 区间第 3 级（Lv1 为 3 级，Lv2 为 8 级） |
| A 级 | 区间第 4 级（Lv1 为 4 级，Lv2 为 9 级） |
| S 级 | 区间第 5 级，即区间最高级（Lv1 为 5 级，Lv2 为 10 级） |

**晋级规则（设计师指定）**

- D 到 A 级任务提交后各算 1 个。累计完成 10 个，公会发布一个 S 级赏金任务。S 级任务不计入这 10 个。
- S 级任务的敌人等级固定为当前危险等级区间的最高级。
- S 级任务失败（死亡）后可以反复挑战。实力不足时，可以先去刷其他 D 到 A 级任务来升级，实力够了再挑战。
- S 级任务提交完成后，按 1.4 的公式给经验（世界危险等级 Lv + 1）× 500，并进入下一个危险等级。
- S 级任务出现后，布告栏继续发布 D 到 A 级任务，期间完成的 D 到 A 级任务仍然计数，但不影响下一危险等级 S 级任务的刷新次数。
- 进入下一个危险等级后，累计完成的任务数从 0 重新开始计数。
- 进入下一个危险等级时，未完成的任务直接失效，并给玩家一个提示；同时立即发布新一批任务。
- 每天早上 6:00 刷新时，已经接取的任务保留，完成后可以提交。
- 地下城的 12 小时跨过早上 6:00 时，回城后任务板补刷新一次（见 2.5）。
- 死亡后游戏时间回退，任务板不随之回退，已刷新的任务保持不变；回退后再次经过早上 6:00，任务板也不会再刷新（设计师指定）。
- 玩家同时最多接 3 个任务，可以放弃任务后重新接。
- 放弃任务时，该任务地下城的进度清空，重新接取后从头开始。
- 敌人经验和任务完成经验都随世界危险等级增长，公式见 1.4；玩家等级上限 999。
- 任务报酬的金币按档位固定，不随世界危险等级增加，见 3.11。
- 世界危险等级跟随每个存档各自的进度：每个存档有自己的世界危险等级和累计任务数。
- 玩家可以接取当前世界危险等级内任意 D 到 A 级任务，不限制玩家等级。每个任务（包括 S 级赏金任务）都带难度标签：玩家等级比敌人等级高 4 级及以上为轻松应付；相差 3 级以内（含 3 级）为旗鼓相当；玩家等级比敌人等级低 4 级及以上为满地找牙（困难）。
- Lv20 的 S 级任务完成后，同样按公式给经验，仍然停留在 Lv20。可以继续刷新 D 到 A 级任务，但不再有 S 级任务。

数学题难度随危险等级变化，见 3.3。

### 3.10 地下城生产模板

每个任务对应一座全新的地下城，由地下城生产模板生成。

**故事（设计师指定）**

- 故事要素为人物、冲突、转变（见 3.5）。
- 故事就是剧情，不涉及数值。
- 呈现方式类似早期国外的 adventure book：玩家读一段剧情，然后出现一个事件，事件规则见 3.5。
- 故事写好之后，用它来指导具体敌人和谜题的分析。
- 一个世界有几百个任务，需要几百个故事。故事用要素库拓展：按人物、冲突、转变的组合，离线写好，逐篇审核后入库。

**生成顺序（设计师指定）**

1. 先按故事要素（人物、冲突、转变）定好剧情。
2. 基于剧情确定地点。
3. 基于剧情确定适配的演员，包括敌人和 NPC。
4. 基于剧情确定谜题。
5. 基于剧情确定故事道具（见 3.4）。
6. 基于剧情确定对应的数学题目。

**配套规则（设计师指定）**

- 怪物的克制标签先跟着种族走，按 1.11 的种族对应表；未来预留修改空间。
- 隐藏主线占位，暂不设计，生成的任务里先不出现。
- 故事写法类似《哈利·波特》，有故事性；世界背景见总纲。
- 3.6 的两座范本和 3.7 的三个故事骨架已按三要素整理，作为故事框架；具体变成故事时，还要丰满和合理化，并继续拓展。
- 数学题的年级由世界危险等级决定，见 3.3。

### 3.11 金币与黑市

金币用于在黑市商人处购买装备或消耗道具，也用于在城镇道具商人处购买小血瓶，见 3.5。黑市商人直接用金币交易，没有数学题。

**金币来源（设计师指定）**：完成悬赏任务、击杀敌人、NPC 救助事件、装备陷阱、在城镇道具商人处卖出装备。

| 来源 | 金币 |
| --- | --- |
| D 级任务完成 | 50 |
| C 级任务完成 | 100 |
| B 级任务完成 | 300 |
| A 级任务完成 | 500 |
| S 级赏金任务完成 | 1000 |
| NPC 救助事件（奖励为金币时） | 20-50 |
| 装备陷阱答对 1 题 | 10 |
| 装备陷阱答对 2 题 | 20 |
| 小怪（每只） | 1-2 |
| 精英（每只） | 5-10 |
| BOSS | 100-200 |

事件里，NPC 救助事件和装备陷阱会给金币，其他事件不给。金币收入都不随世界危险等级变化（设计师指定）。

**NPC 救助事件的奖励（设计师指定）**：按概率随机，装备 35%，血瓶 30%，金币 35%。奖励为装备时，品质为白色 70%、蓝色 30%。奖励为血瓶时，小血瓶 60%、中血瓶 40%。

**黑市商品（设计师指定）**

| 商品 | 价格 | 效果 |
| --- | --- | --- |
| 白色装备 | 50 金币 | 属性规则见 1.9 |
| 蓝色装备 | 200 金币 | 属性规则见 1.9 |
| 黄色装备 | 1000 金币 | 属性规则见 1.9 |
| 小血瓶 | 10 金币 | 回复 10% 最大 HP |
| 中血瓶 | 50 金币 | 回复 30% 最大 HP |
| 魔法瓶 | 占位 | 先不出现 |

**黑市商人出现规则（设计师指定）**

- 黑市商人是否出现由故事情节决定，情节里不适合放商人就没有商人（设计师指定）。
- 出现时一次展示 3 件装备和 2 个血瓶，卖完就没了。
- 装备的品质：白色 50%，蓝色 30%，黄色 20%，每个槽位独立概率。
- 血瓶的种类：每个血瓶独立判定，小血瓶 60%，中血瓶 40%。

**城镇道具商人（设计师指定）**

- 城镇里有道具商人，出售小血瓶，也收购玩家背包里的装备。
- 小血瓶的价格和效果与黑市小血瓶相同：10 金币，回复 10% 最大 HP（见上表）。
- 小血瓶每天早上 6:00 刷新为 5 瓶（住酒店醒来就是早上 6:00；地下城的 12 小时跨过 6:00 时，回城后补刷新一次，见 2.5）；当天没买完，第二天也还是 5 瓶，不累计。死亡后游戏时间回退，道具商人的库存不刷新，回退后再次经过早上 6:00 也不刷新（设计师指定，与任务板规则一致）。
- 只有城镇道具商人回收装备，黑市商人不回收装备。
- 回到城镇后才能卖装备，卖出价格是黑市同品质装备售价的 1/10。
- 只有背包里的装备可以卖，身上已穿戴的装备不能卖。
- 酒店老板没有物品栏售卖框，不能卖背包里的物品。

### 3.12 背包与道具

地下城的玩法类似 Dungeon Crawler（地城爬行），玩家可以从背包里使用道具（设计师指定）。

| 道具 | 使用时机 |
| --- | --- |
| 血瓶 | 战斗中和战斗外都可以使用 |
| 故事道具 | 只有 BOSS 战中可以使用，见 3.4 |

- 背包默认 100 格，装备、血瓶、故事道具都占背包格子（设计师指定）。
- 背包满时，新获得的物品直接丢弃，并提示玩家背包已满；能叠进背包里已有血瓶格子的血瓶照常收下（设计师指定）。
- 背包满时不能购买，提示背包已满；能叠进背包里已有血瓶格子的血瓶仍然可以购买（设计师指定）。
- 血瓶堆叠在一个格子里（设计师指定）。
- 道具没有使用数量限制。
- 战斗中使用血瓶不占用答题机会；血瓶够用就可以一直回血（设计师指定）。
- 血瓶回复的百分比基于玩家最大 HP。
- 死亡会丢失本次地下城中的所有收获，非本次地下城所得保留，见 2.4。

### 3.13 血量爱心

画面右下角有一个爱心，随心跳跳动（设计师指定）：

- 血量高于 20% 时，每 1 秒跳动一次。
- 血量在 20% 以下时，每秒跳动 3 次（设计师指定）。
- 爱心只做大小跳动，没有闪烁（设计师指定）。
- 不使用整屏的红色遮罩，因为红光对视力不好。

### 3.14 地下城界面（设计师指定）

地下城用冒险书（adventure book）的形式呈现，竖屏。

- 顶部不显示时钟，显示事件的面包屑，提示玩家现在到了第几个事件，当前事件上有一个小箭头。
- 上半屏是一幅像素画，大致描绘当前事件；怪物战斗时画怪物，并有场景背景。
- 下半屏是文字：先是一小段描述，然后是数学题题干；选项就是数学题的答案，用选择题的形式；选择后给出结果反馈。
- 底部是背包，点击可以查看里面的道具（见 3.12）。
- 右下角是血量爱心（见 3.13）。
- 地下城通关，或在营地离开地下城，游戏时间直接加 12 小时（见 2.5）。

## 五、存档与登录

> 这是一个单人游戏，存档和登录都保持简单（设计师指定）。

### 托管约束

游戏发布在 GitHub Pages（`https://ypingzhao.github.io/Oscar-adventure-game/`），这是纯静态文件服务：没有服务器进程、数据库和后端 API，页面里的代码任何人都能看到。

### 登录（设计师指定）

- 登录界面有一个密码框和一个确认按钮，没有用户名。
- 口令输错时，提示「密码错误，请重新输入」，并清空密码框。
- 浏览器记住已登录，下次不用再输；换浏览器、无痕模式、清除网站数据后要重新输入。
- 口令不明文写入文档，也不明文写进页面代码，页面里只存校验值。

| 方面 | 说明 |
| --- | --- |
| 校验位置 | 口令只能在浏览器里校验，所以它是一道入口门，不是安全措施 |
| 校验值 | 口令如果较短，校验值仍然可以被穷举还原 |

### 开始页（设计师指定）

- 开始页显示游戏名称，以及「新游戏」「继续」「选择存档」三个按钮。
- 「继续」：从最近一次存档的进度开始。
- 「选择存档」：从三个存档位中选择一个开始。
- 一个存档都没有时，「继续」和「选择存档」按钮隐藏（设计师指定）。
- 「新游戏」：自动使用编号最小的空白存档位，不让玩家多选一步；然后进入种族选择界面，选好种族后进入城镇（见 1.10）。
- 三个存档位都满时，点「新游戏」跳转到存档页，点击一个存档会提示是否删除，删除确认同下方「存档」里的 3 秒倒计时；删除后直接用这个空出来的存档位开始新游戏，进入种族选择（设计师指定）。

### 存档（设计师指定）

- 提供三个存档位（设计师指定）。
- 新游戏自动使用一个空白存档位（见开始页）。游戏里没有覆盖存档的功能，只有删除（设计师指定）。
- 删除存档位：弹出确认窗口，窗口弹出后有 3 秒倒计时，倒计时结束后「是（删除）」按钮才可以点击（设计师指定）。
- 自动存档，只存在本机浏览器里（设计师指定）。
- 自动存档的时机（设计师指定）：住酒店、进出地下城、完成事件、完成任务、死亡后。
- 中途退出游戏再回来，回到当前事件的开头；战斗或答题进行到一半时退出，也回到这个事件的开头（设计师指定）。

### 分享存档（设计师指定）

- 每个存档位下有一个「分享」按钮，点击后生成令牌，并自动复制令牌字符串，可以发给别人（设计师指定）。
- 别人在游戏里输入令牌，可以再现存档的进度。
- 用别人的令牌导入存档，必须放进空白存档位，不能覆盖已有存档；三个存档位都已有存档时，需要先删除一个存档（设计师指定）。
- 令牌输入错误时，提示「输入令牌错误」（设计师指定）。

令牌的长度现在不估算，做出来以后用真实存档测试，再看多长合适。

令牌的编码方式在技术设计阶段确定。

### 存档内容（草案）

下面的字段是为了加载游戏用，功能定稿后再调整。

```json
{
  "version": 1,
  "savedAt": "2026-10-09T18:30:00+08:00",
  "character": {
    "name": "Oscar",
    "race": "cat",
    "level": 2,
    "exp": 145,
    "stats": { "str": 5, "int": 10, "vit": 15, "luck": 3 },
    "hp": 12,
    "gold": 20,
    "inventory": [{ "id": "small_potion", "count": 3 }],
    "equipment": []
  },
  "world": {
    "dangerLevel": 1,
    "questsDone": 4,
    "activeQuests": [{ "id": "farm_01", "grade": "C" }],
    "location": "town",
    "gameTime": 1440,
    "abilityUsed": { "dogSmell": false, "crocodileRoll": false }
  },
  "dungeons": {
    "farm_01": {
      "doneEvents": ["e1", "e2"],
      "currentEvent": "e3",
      "storyProps": ["story_prop_1"],
      "loot": ["gold:35"]
    }
  },
  "memory": {
    "revealedRaces": ["僵尸动物"],
    "deathsByType": { "两位数进位加法": 1 },
    "diedAt": ["farm_01"],
    "lifeCount": 3
  }
}
```

- `world.dangerLevel`、`world.questsDone`：世界危险等级和累计完成任务数，每个存档各自的进度（见 3.9）。
- `world.gameTime`：游戏时间，死亡后回退（见 2.5）。
- `world.abilityUsed`：狗的嗅觉、鳄鱼的死亡翻滚自上次住酒店休息后是否用过，住酒店休息后恢复。
- `dungeons.<id>.doneEvents`：已完成的事件，重新进入同一座地下城时不再出现（见 3.5）。
- `dungeons.<id>.currentEvent`：当前所在的事件，中途退出游戏再回来时回到这个事件的开头。
- `character.equipment`：已穿戴的装备，每件装备对应的部位见 1.9。
- `dungeons.<id>.loot`：本次地下城的收获，死亡时丢失，主动离开时保留（见 2.4、3.1）。
- `memory.deathsByType`：每个题型死亡的次数，决定提示给多少（见 2.2）。
- `memory.lifeCount`：轮回数，主界面显示「第 N 次人生」（见 2.4）。

## 七、风险清单

| 风险 | 说明 | 对策 |
| --- | --- | --- |
| **孩子跳过文字直接打** | 悬疑剧本变装饰 | **谜题与真相**（3.4）：解谜才能看到 BOSS 的弱点 |
| **推理太绕孩子想不明白** | 挫败 | 每个谜底一句话能说清 |
| **数学题变成作业感** | 孩子一旦觉得在做题就跑 | 包装进叙事；答错只扣血，单题不致死；每题不超一屏三分之一 |
| **文字量过大** | 8-10 岁读 100 字就累 | 每屏 ≤60 字；短句；关键词高亮 |
| **内容工作量被低估** | 地下城由生产模板生成，要写的是模板和素材库（故事、地点、演员、谜题、故事道具、数学题），工作量待估算 | 先用南方农场当模板，再批量复制 |
| **BOSS 太难卡死** | 反复失败会放弃 | 营地可离开地下城，离开后进度重置 |
| **死亡机制伤害低龄玩家** | 8 岁孩子可能真的会难过 | 轮回数当徽章；重生必有确定收益；不嘲讽、不显示 Game Over |
| **Lv1 死亡率过高** | 开局偏硬，孩子可能前期多次死亡（靠试玩观察） | 试玩观察；可调：体力初始值（B5）、扣血规则、敌人 HP |
| **难度自适应失灵** | 孩子可能卡在年级内某一档反复失败 | 答错 2 题降档是硬规则，不靠猜（只在当前年级内增减难度） |

### 8.4 执行顺序

1. 做 **P1 引擎**，先写南方农场（结构最标准，做完就是模板）
2. 按第四节 C 组拿去给孩子试玩
3. **P2 内容不要一次写完。** 先写一小批任务（数量待定），试玩后再决定后面怎么写，避免整体写错方向

**C6 是最该验的一条。** 「允许死亡」是整个设计最大的政策选择，成不成立只有真孩子能回答：大人算得出死亡率这个数，算不出孩子死了之后会怎么想。

**第 2 步不能跳。** 儿童游戏最大的风险是大人觉得设计得合理、孩子根本不玩，只有真实试玩能发现。
